# Project State — gate-tools-rewrite

> 本文件只放**推理**：设计取舍、被否决的方案、坑的定性。
> 路径清单与命令证据在 `handoff.md`；不在这里复述。

## 1. 为什么"重写"而不是"移植"（KAI 裁定）

**被否决的方案**：从 `HEAD` 移植旧 `tools/` 的 43 个文件，逐个改层号。
理由曾是"旧版更成熟"（`period_reference` / `group_guard` / `period_selftest`
是 7 组对照 + 完整性守卫 + 变异自检）。

**KAI 2026-09-15 明令否决**：**"必须重写，禁止移植失败品"**。

**为什么移植确实是错的**（不只是"KAI 不喜欢"）：

| | 旧 | 新 |
|---|---|---|
| 层数 | 6 | **9** |
| `serialization` | **L4** | **L6** |
| `contracts` | L0 | L0 |

机械字符串替换会把 `serialization` 的层号判据整体错位 —— 而**层号错位不会报错**，
只会让 `[2]` 的依赖方向检查**放过真实的反向依赖**。这正是本项目头号禁忌
（静默错值）的门禁版：**门禁自己静默失效**。

⇒ 结论：**门禁的可信度不能建立在"改对了 43 个文件的层号"这个人工步骤上。**

## 2. 六处对旧版的改进 —— 每一条都在修"门禁自己会静默失效"的通道

共同主题：**旧版的判据会在"什么都没查"的情况下报通过**。

1. **`[3]` 补 JSON 重复键检测**
   `json.loads` 对重复键**静默取最后一个** ⇒ 一个被写了两遍的键，配置值取决于
   书写顺序，而**没有任何工具能发现**。必须用 `object_pairs_hook` 才数得出来。
   **这是配置版的静默错值。**

2. **`[5]` 改为键级完整性，砍掉手工 `REQUIRED_KEYS`**
   旧版有一张"11 模块 × 若干键 = 必须存在的键"的手工清单。**清单会腐烂**：
   新增一个键就要回来改工具，忘改就漏检。而 `config/loader.py` 已 fail-fast，
   "声明的键必须被读、读的键必须被声明"由 `[7]` **双向推导**覆盖 ⇒
   机制覆盖了那张清单的全部职能。**判据从"清单"升级为"推导"。**

3. **`[13]` 帧字段清单从 `dataclasses.fields(Frame)` 派生**
   旧版的手工清单**已经腐烂**：`("seq","ts","spot","session","health","heatmap",
   "skew","cells","atm")` —— **漏了 `surface`**。而 `surface` 恒为 `null`
   正是上一轮修掉的静默缺口 ⇒ **旧判据对这个缺口一行都查不出**。
   派生式判据配 `FOLDED_FIELDS`（显式声明哪几个契约字段折叠进哪个段）+
   `EXTRA_TOP_LEVEL_KEYS`（显式声明哪些顶层键不属于契约）。

4. **`[2]` 层表覆盖核对**
   旧版对不在 `LAYER_OF` 里的包直接 `continue` ⇒ 新增一个包时该包的跨层 import
   **一行都不检查**，输出照旧"未发现反向依赖"。
   **通用教训**：凡"查表 + 表里没有就跳过"的检查，都要配一条"表是否覆盖全集"的断言。

5. **`--selftest` 判据：从"RC 非 0"升级为"目标检查项自己报了 FAIL"**
   见 §3。

6. **`[12]` 内建反证**
   "注入时钟驱动裁剪"这条判据若只断言"丢弃了 > 0 条"，无法排除"其实验的是墙钟"
   （墙钟也会丢弃未来样本）。加一条**反证**：同一组未来样本改用 `WallClock()`
   裁剪 ⇒ 必须丢弃 **0** 条。**反证才是让判据可归因的东西。**

## 3. 判据设计：为什么"退出码非 0"是不够的

**被否决的判据**：`if result.returncode != 0: 抓住了`。

**问题**：`--selftest` 注入 `[14]` 的缺陷后，若 `[1]` 因为无关原因变红，
`returncode` 也是非 0 ⇒ 判据报"`[14]` 抓住了" —— **结论是假绿**。

**采用**：按段落编号（`^\[\d+b?\]`）切出**目标检查项自己那一段**，看它有没有
`[FAIL]`。

```python
_SECTION_RE = re.compile(r"^(\[\d+b?\])", re.MULTILINE)

def _section_failed(output: str, number: str) -> bool:
    matches = list(_SECTION_RE.finditer(output))
    for i, match in enumerate(matches):
        if match.group(1) != number:
            continue
        end = matches[i + 1].start() if i + 1 < len(matches) else len(output)
        return "[FAIL]" in output[match.start():end]
    return True          # 找不到该段 ⇒ 视为失败（宁可报红，不可报假绿）
```

⚠️ **连带要求（最容易漏的一条）**：**段落标题必须打在 `run_*_checks()` 里**，
不能只在各文件的 `main()` 里打。编排器调用的是 `run_clock_checks()` /
`run_connectivity_checks()` / `run_router_checks()` —— 标题若只在 `main()` 里，
`_section_failed()` **切不出该段** ⇒ 走 `return True` 分支 ⇒
**恒判为"抓住"（判据恒真 = 空转）**。
三处 docstring 均已写明此理由，防止后人把标题搬回 `main()`。

## 4. 三个真缺陷的定性

### 4.1 `bucket_seconds_s` —— 注释描述了一个从未实现的机制

**不是"死键"这么简单**。定性链：

1. 全工程**零读取点**（唯一出现在 `tmp/` 的一次性探针，不算产品代码）。
2. 注释写"推送必须对齐世界时间桶边界"，而 `PushLoop` 只按**固定节奏 +
   帧序号变化**触发 —— **从来没有桶对齐逻辑**。
3. 该键**在旧项目 `HEAD` 的 `transport.json` 里根本不存在** ⇒
   它是上一轮移植时**凭注释描述"补"出来的**。

**为什么必须删**：注释描述了一个**从未实现的机制** = 一份**过期的真相**。
下一个会话读到"推送对齐桶边界由 `bucket_seconds_s` 控制"，
很可能就去**实现**它 —— 凭空多出一个没人要的机制，而且**新增的键看起来完全合理**。

⇒ **载体是注释的静默错值**。与"程序照常出图但数值错了"同族。

**处置**：删键；注释改写为 `_push_comment`，明写"**不对齐是刻意的**"并给出量级
（差 ≤ 1 个推送周期 = 400ms，相对 30s 桶 = 1.3%）；并留一句
"若日后确要对齐，须同时加键、实现、并在注释里写明"。

### 4.2 键转发器 —— `[7]` 的覆盖盲区

**现象**：`svi_bounds` / `ssvi_data_start` / `ssvi_random_start_ranges` /
`svi_allowed_statuses` / `svi_random_start_ranges` 5 个**活键**被报"无代码读取"。

**根因**：`models/surface_params.py::_param_pairs(cfg, key, ...)` 把键名**当参数
转发**给 `loader.get(cfg, key, ...)`，而字面量收集器只认字符串字面量。

**⚠️ 假红比漏检更危险**：5 个假红会让人**不再相信 `[7]`**，
进而忽略它报出的那 1 个**真死键**。⇒ 必须修覆盖，不能加例外表。

**修法**：`tools/selfcheck_reads.py` 做**两遍 AST 扫描** ——
① 先找出本文件的**键转发器**（形如 `def f(cfg, key)` 且体内把 `key` 传给
loader 取键函数的参数位置）；② 再扫调用点，把实参代入。

**边界处理（宁可不判也不猜）**：同名转发器在多个文件声明**不同** `module` ⇒
归入 `unresolved`，不参与推导。

**效果**：读取点 **168 → 173**，5 个假红消失。
（⚠️ **当轮值**，不是当前值 —— 该计数随代码变化，引用请实跑 `[7]`，**不要从本档案抄**。）

**⚠️ 同一坑的第二次出现**：本轮在 `selfcheck_config_invariants.py` 里写了个
`_as_int(cfg, key, module)` 辅助函数，把 `module=` 也变成参数转发 ⇒ `[7]` 报
9 条"无法静态解析"。**修法 = 删掉辅助函数**，逐键直接
`loader.as_int(cfg, "key", module="literal")`。
⇒ **教训：检查器自己也要受它检查的那条规则约束。**

### 4.3 `--selftest` 报 `[14] 没抓住` —— 但根因是变异写错了

**⚠️ 这是本会话最值得记的一条：`变异无效` 与 `判据空转` 是两种病，修的地方不同。**

**现象**：`[14]` 的变异（把"明确要求只用模型值时不接受降级来源"的
`return None` 改成 `continue`）跑下来判据没红。

**排查过程（含一次误判）**：
- 手工复现变异 ⇒ 锚点命中 **0 次**；而 `--selftest` 走的是"没抓住"分支
  ⇒ 两者**矛盾**。
- 诊断脚本打印 `repr()` 时发现 `\n` 被 Git Bash 的 **MSYS 路径转换**吃成 `/n`
  （KAI 记过的 `MSYS_NO_PATHCONV` 陷阱）—— **但这不是根因**，只是干扰。

**真根因**：**变异本身写错了**。原代码 `return None`（立即拒绝）被改成
`continue`，但循环里后续的 bid/ask 槽位**通常是空的** ⇒ 最终**仍然 `return None`**
⇒ **行为与原代码完全等价** ⇒ 判据当然不会红。

**修法**：变异改为 `return comp, tick_type`（**真正接受**降级），并在变异表里
留注释说明这个陷阱：

```python
# ⚠️ 变异必须写成 `return comp, tick_type`（**接受**降级），不能写成
# `continue`。写 `continue` 时循环会继续往下走，而 `_COMPUTATION_SOURCES`
# 里后面的 bid/ask 槽位通常是空的 ⇒ 最终仍然 `return None` ⇒ **行为与
# 原代码完全等价**，判据当然不会红。**变异必须真的改变行为** ——
# 否则"抓住了"和"没抓住"两个结论都不可信。
```

**判据**：一条变异是否有效，判据是"它是否改变了可观测行为"，
**不是"它是否改了源码文本"**。

## 5. 夹具填充度 = 判据是否空转

`[13]` 首版 `_minimal_frame()` 的 `zones` **留空** ⇒ "区段表非空"判据在
**0 段**下也打印通过。修法：填 **3 段** `SessionZone`（gth / gap / rth），
判据改为 `len(zones) >= 2`。

**同类已在本项目出现过三次**：
1. 本节 —— `zones` 留空。
2. `web_e2e` —— 真实帧按绝对桶号索引、夹具只喂最后 7 桶 ⇒ `g=5` 时
   **可比格数 = 0**，"最大误差 0"恒真（`ARCHITECTURE.md §15.2`）。
3. `[12]` 夹具 —— **锚定日必须落在墙钟之后**（`ANCHOR_DAY = 2030-01-01`
   的下一个工作日），否则"注入时钟"与"墙钟回落"给出相同结论 ⇒ 判据空转。

⇒ **通用判据**：任何"比较型"断言，都要**报出实际比较格数**，
并在夹具里保证它 > 0。

## 6. 配置注释里的"已有东西守着" —— 一次成批的过期真相

**发现**：`grep` 配置目录 ⇒ 6 处引用**不存在**的检查器
（`check_matrix_codec` / `check_reconnect_gap` / `check_session_grid` /
`check_surface_payload` / `check_window_tolerance` / `check_ws_compression`），
`find` 逐个确认 **8 个全部不存在**。

**定性**：与 `bucket_seconds_s` **同一族** —— 注释断言"由 `tools/check_X.py` 守住"，
而 `X` 不存在 ⇒ 读者会以为**已经有东西守着**，于是不去看那条契约。

**处置**（本轮）：**不建检查器**（KAI 未指令），而是把 6 处引用**逐条标注"待建"**
并指向 `README.md §6` 的状态表。理由：**在检查器建出来之前，
注释是设计意图而非既成事实** —— 这句话本身必须写在注释里。

**未选方案**：把注释里的检查器名**整段删掉**。否决理由 —— 那会丢掉
"这条契约该由什么守"的设计意图；而**意图是有价值的**，缺的只是"它还不存在"这个事实。
