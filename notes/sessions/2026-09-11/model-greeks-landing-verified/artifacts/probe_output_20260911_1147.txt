观测要点（供判读）

1. **modelGreeks 非空**：iv=12.48% / delta=0.4391 / gamma=0.01883 /
   vega=0.6621 / theta=-6.8369。`config/ibkr.json` 的
   `generic_tick_list: "106"` 确实打开了 `tickOptionComputation`。

2. **modelGreeks 与 bid/ask/last 三档 greeks 明显不同**（不是同一份数据的拷贝）：
     属性        iv        delta
     model     0.12483    0.43913   ← MODEL_OPTION（tickType 13）
     bid       0.12329    0.46919   ← tickType 10
     ask       0.12629    0.46995   ← tickType 11
     last      0.11728    0.46756   ← tickType 12
   四者并存 ⇒ 它们来自不同的 tick 通道，MODEL_OPTION 是**独立存在**的一条。
   项目 `use_model_greeks: true` 时 `TickRouter._pick_computation()` 只接受
   modelGreeks（其余一律 return None），所以项目拿到的就是第一行那组值。

3. **marketDataType = 1（实时），不是 3（延迟）。**
   标的现价那条 ticker 报 3（符合 `reqMarketDataType(3)`），
   但**期权合约的 ticker 报 1** —— 说明 IB 对这张 SPXW 期权**给的是实时数据**。
   同时 Error 10090 的原文是 "**Part of** requested market data is not
   subscribed"（**部分**未订阅），并非"完全没有权限"。
   ⇒ 此前"paper 账户无实时 OPRA 权限，只返回延迟数据"的假设**与本次观测不符**。

4. 探针绕开了项目代码，但订阅参数与项目**逐字相同**
   （SPX / IND / CBOE / SPXW / SMART / genericTickList="106" / marketDataType=3），
   因此结论可外推到项目路径。项目路径的交叉证据见
   `notes/context/project_state.md` 记录的 2026-09-11 实盘读数
   （ATM IV 15.70/16.83、25Δ Skew、热力图 36 格有效数值）——
   在 `use_model_greeks=true` 下这些 IV/Δ **只能**来自 modelGreeks。

5. 未验证的残留：**无法从 ib_async 属性层区分 tickType 是 13（实时模型）
   还是 83（延迟模型）** —— 库的 `GREEKS_TICK_MAP` 把两者合并到同一个
   `modelGreeks` 属性。`TickRouter` 也因此把 `source_tick_type` 一律记为 13。
   本次观测到 marketDataType=1，倾向于是 13，但这是间接推断。
